# Xinxiu Wang

Personal academic website for Xinxiu Wang, doctoral student in Operations Management at the University of Miami. Built for GitHub Pages with plain HTML and CSS; no installation or build step is needed.

## Publish

1. Create the repository `XinxiuWang/xinxiuwang.github.io` on GitHub. Do not overwrite an existing repository.
2. Upload the contents of this directory to its `main` branch, retaining the `assets` and `files` directories.
3. In Settings → Pages, select **Deploy from a branch**, choose **main** and **/(root)**, and save.
4. Wait for GitHub's Pages deployment to finish, then verify the live website before using its URL in an application.

Expected URL after successful deployment: `https://xinxiuwang.github.io/`. This URL is not live merely because these source files exist.

## Update

- Edit `index.html` to update the biography, research, or teaching.
- Replace `files/CV_Xinxiu_Wang.pdf` with the current CV without renaming it.
- Replace `assets/xinxiu-wang.jpeg` to change the portrait.
- Adjust the visual styling in `style.css`.

Working papers are listed with abstracts or project overviews and email requests only, following the owner's preference. Their full PDFs, references, transcripts, evaluations and school-specific application packets must remain outside this repository.
